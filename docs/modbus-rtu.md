# 水表 MODBUS-RTU 通讯协议（整理版）

> 依据厂家文档《水表MODBUS-RTU通讯协议 V1.4》整理，并与固件实现（`main/water_meter.c`、
> `main/modbus_rtu.c`）逐条核对过。原始 `.doc` 不在仓库里，需要对照可向厂家索要。

## 1. 物理层

| 项 | 值 |
|---|---|
| 接口 | RS485，半双工，主从应答 |
| 波特率 | **9600 bps**（默认，可改 4800 / 2400 / 1200） |
| 数据格式 | 8 数据位、无校验、1 停止位（8N1） |
| 帧间隔 | ≥ 3.5 个字符时间（9600bps 下约 4 ms） |

线序（水表自带四芯线）：

```
红线：12V DC（供电范围 DC 9–24 V）
黑线：GND
黄线：A
蓝线：B（有的批次是绿色）
```

> 水表由这根线供电，所以 RS485 不仅是通讯线，也是电源线。

## 2. 帧格式

```
地址码(1B) 功能码(1B) 数据区(nB) CRC16(2B, 低字节在前)
```

- 地址码：1–247（广播 00）
- CRC16：初值 `0xFFFF`，多项式 `0xA001`（标准 Modbus CRC，低字节先发）

## 3. 功能码

| 功能码 | 定义 | 用途 |
|---|---|---|
| `0x03` / `0x04` | 读数据寄存器 | 读累计水量（固件用 `0x03`） |
| `0x10` | 预置多寄存器 | 改通讯地址 / 波特率 |
| `0x05` | 开关阀门控制 | 起始地址 `0x0001`，写 `0xFF00` 开阀 / `0x0000` 关阀 |
| `0x01` | 读阀门状态 | 起始地址 `0x0001`，数量 1，`0xFF` 开 / `0x00` 关 |

## 4. 寄存器表

| 地址 | 名称 | 读写 | 格式 |
|---|---|---|---|
| `0x0000`–`0x0001` | 总用水量 | R | 4 字节（高位在前），单位 m³ ×0.01 |
| `0x0015` 高字节 | 通讯地址 | R/W | 1–247 |
| `0x0015` 低字节 | 波特率 | R/W | `01`=9600（默认）`02`=4800 `03`=2400 `04`=1200 |

水量换算：原始值 `0x0012D687` = 1234567 → **12345.67 m³**（除以 100）。

## 5. 报文示例

读累计水量（从站 1，读 2 个寄存器）：

```
主 → 01 03 00 00 00 02 C4 0B
从 → 01 03 04 00 00 12 D6 xx xx        （数据 4 字节，高字在前）
```

开阀 / 关阀（功能码 05，地址 0x0001）：

```
开阀  主 → 01 05 00 01 00 FF xx xx
关阀  主 → 01 05 00 01 00 00 xx xx
```

读阀门状态（功能码 01，地址 0x0001，数量 1）：

```
主 → 01 01 00 01 00 01 xx xx
从 → 01 01 01 FF/00 xx xx      （标准：字节数 + 位图）
```

> ⚠ 现场这台表的 `0x01` 应答**不是标准格式**：它回的是"地址 + 值"回显式帧
> （8 字节，第 6 字节 `0xFF` 表示开阀）。固件两种格式都认（见 `water_meter.c`
> 里的 `water_meter_read_valve`），否则换表或换固件就会误判阀门状态。

## 6. 从站地址怎么定

表盘上印的是 12 位数字地址，**取后两位按 16 进制**就是 Modbus 从站地址：

```
表盘地址 00201908004567 → 后两位 67 → Modbus 地址 0x67（十进制 103）
报文：67 03 00 00 00 02 CD CD
```

固件里默认 `WM_SLAVE_ADDRESS = 1`，改地址只需要改 `main/water_meter.c` 里这一个宏。

> 本台表：表盘地址后两位为 `01`，即从站地址 **1**，与固件默认值一致，无需改动。
